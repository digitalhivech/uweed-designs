The approved uWeed logo kit and two secondary marks. The kit was copied from the brand's own source folder (`01 SVG — Approved`, `02 PNG — Digital`, `04 Usage Guide`), working set as of August 2026.

**About these copies.** The two favicon PNGs are byte-identical to the originals. The 22 SVGs render pixel-identically to the originals, but are not byte-identical: this system's file store removes embedded stylesheets from SVG, and the original logo and tagline files set their colour in one. Each of those 16 files therefore carries its colour as a `fill` attribute instead. Geometry was not touched. For anything outside this system (print, agencies, press), hand over the originals from the source folder, not these copies.

Not copied here: the `@2x` PNG exports, the social avatars and the print PDFs. They are not website assets; they stay in the source folder.

**Secondary marks (October 2026).** Two further marks were added on 8 October 2026: the **badge** (the mark in a double ring, `uweed_badge_*.svg`) and the **stamp** (the mark in a ring with the brand line "Delivering Happiness", `uweed_stamp_*.svg`), each in the same eight colourways as the logo. They were supplied as 2000px raster images and traced to vector here; the geometry follows the supplied artwork, but if vector originals exist in the source folder, they replace these files. Their rules are in the brand book under *Logo* and on the `Logo` page; the usage guide below predates them.

# uWeed Logo Kit — Usage Guide

## Start here

Use the SVG assets whenever the receiving platform supports SVG. They stay sharp at any display size and are the approved default for web, Klaviyo and digital production.

Use PNG only where SVG is unsupported. The `@2x` files are high-resolution exports for normal digital use. Do not make a logo larger than its source image.

## Choose the lockup

| Need | Use |
|---|---|
| Default website, email header or document | `uweed_logo_horizontal_dark-blue.svg` |
| Dark, coloured or photographic background | `uweed_logo_horizontal_white.svg` |
| Brand-led editorial surface | `uweed_logo_horizontal_dark-pink.svg` |
| Commerce surface where green is already the intended family | `uweed_logo_horizontal_dark-green.svg` |
| Brand presentation with enough space | A matching `horizontal-tagline` file |
| Social profile, favicon or tiny UI space | `uweed_mark_*.svg` or a supplied favicon PNG |
| One-colour production where black is mandatory | A `_black` asset |

## Colour rules

| Asset colour | Token | Background |
|---|---:|---|
| Dark blue | `#0B102A` | White or light tint |
| White | `#FFFFFF` | Dark blue, dark green or dark pink |
| Light blue | `#CED4F3` | Dark blue only |
| Light green | `#D1EFE5` | Dark blue only |
| Light pink | `#F4E2ED` | Dark blue only |
| Dark green | `#286754` | White or light green |
| Dark pink | `#78596F` | White or light pink |
| Black | `#000000` | Restricted production only |

Do not recolour an asset, add an outline, shadow, gradient or background box, stretch it, or reconstruct the logo with a font.

## Size and clear space

| Lockup | Minimum digital width |
|---|---:|
| Horizontal logo | 100 px |
| Horizontal logo with tagline | 180 px |
| Mark | 24 px |
| Favicon | Use the supplied 32 px or 180 px PNG |

Keep clear space around every logo equal to at least 25% of the mark height. If this cannot be respected, use the mark or remove the tagline rather than shrinking the logo.

## File structure

- **01 SVG — Approved**: source-of-use digital files
- **02 PNG — Digital**: ready-to-upload raster versions
- **03 Print — Vector PDF**: production-ready vector PDFs
- **04 Usage Guide**: this guide
