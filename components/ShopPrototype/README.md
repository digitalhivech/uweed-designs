# Shop prototype

A clickable mock of the uweed.ch shop, built only from this design system's components.

Click through it to see the components working together: answer the age gate, filter and sort the category listing, open a product, add it to the cart (the cart drawer opens), go on to the cart page and checkout, or open the blog from the main navigation.

- **Stand-ins, not recreations:** the header, mega menu and mobile menu are not designed yet, so the header here is assembled from `Logo`, `SearchBar`, `Badge`, `Link` and `Icon`. Card radios stand in for the variation selector. The filter panels are the documented dropdown surface.
- **Placeholder content:** every image is a flat token-coloured placeholder, six tiles stand in for 284 products, and the checkout sends nothing.
- **Source:** the screens are in `ui_kits/uweed-shop/` (see its README). This preview is those files compiled into one page.
