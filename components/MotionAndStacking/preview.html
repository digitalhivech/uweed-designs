Motion

Three durations, one easing. Reduced motion is a global policy, not a per-component habit

--motion-fast 150ms

Colour, border, opacity

--motion-base 250ms

Panels, disclosure, transforms

--motion-slow 400ms

Full-surface transitions

Easing is one value: --motion-ease cubic-bezier(0.4, 0, 0.2, 1). Every hover effect is gated behind @media (hover: hover) and (pointer: fine) — without it, :hover sticks after a tap on touch. Verify hover with a real pointer: headless Chrome reports pointer: none, so every hover rule legitimately reads as dead in tooling.
