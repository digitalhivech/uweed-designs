# uweed-designs

Design system documentation for uweed.ch.

## Contents

- **[UWEED-08-Design-Tokens-v1.md](UWEED-08-Design-Tokens-v1.md)** — design tokens: palette, typography, spacing, radii, shadows, z-index, breakpoints, and usage rules. The only place values are declared.
- **[UWEED-09-Component-Library-v0.1.md](UWEED-09-Component-Library-v0.1.md)** — component library: anatomy, variants, states, tokens consumed, reference implementations, responsive behaviour, and accessibility for every reusable component.
- **[component-gallery-primitives.html](component-gallery-primitives.html)** — rendered companion to doc 09. Every variant and every state, live, on one page. Open it in a browser. Also published as a [Claude artifact](https://claude.ai/public/artifacts/6f583f52-2c2e-4f81-ac39-b64ca3f8503a).
- `*.md.docx` — original document exports the markdown files were converted from.

## For AI-assisted design work

`CLAUDE.md` instructs Claude (Claude Code, Claude Design) to treat doc 08 and doc 09 as the source of truth for all design output in this repo: tokens only, reference implementations first, semantic color rules, German copy first, accessibility as spec.
