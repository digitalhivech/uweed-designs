# Token changelog

Generated by the design system sync. Each entry records what moved between the
uWeed Design System artifact and this repository on a given day.

`tokens/tokens.json` and `dist/tokens.css` are generated — never hand-edit them.
Change a value in the design system or in `UWEED-08-Design-Tokens-v1.md`, then
re-run the sync.

---

## 2026-09-18 — first landing of the generated token set

**No value changed.** Every token the design system and doc 08 both carry holds
the same value — 96 of them, checked one by one. This entry adds the machine-readable
copy that has never reached the repository, not a correction.

Added:

- `tokens/tokens.json` — 113 tokens across colour, spacing, radius, elevation,
  motion, font weight, line height, letter spacing and the type/layout family,
  each with the usage note from the design system, plus the type scale and the
  two font families.
- `dist/tokens.css` — 117 custom properties generated from it: the 113 tokens,
  `--ff-heading`, `--ff-body`, and the two product-tile type sizes.
- `.design-system-sync.json` — the stamp the next run compares against.
- This file.

Reconciled without a change:

- **Hex case.** The design system stores `#0b102a`, doc 08 documents `#0B102A`.
  Doc 08 Part 7 asks for lowercase in source and uppercase in documentation, so
  both are already correct. `dist/tokens.css` is source and is lowercase.
- **`--font-color` and `--heading-color`.** The design system writes these as
  aliases in its own notation; they are emitted here as `var(--dark-gray)` and
  `var(--dark-blue)`, which is what doc 08 declares.
- **`--ls-caps`.** Doc 08 spells it `+0.04em`, the design system `0.04em`. CSS
  treats the two identically. Doc 08's spelling is used here, per the rule that
  its spelling wins on a formatting-only difference. Nothing renders differently.
